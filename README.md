# Mini Inventario

Proyecto de una aplicación web para registrar y consultar productos de un inventario.

## Requisitos

- Node.js 22 (versión 22.20 o posterior dentro de la serie 22) y npm.
- Python 3.12.

## Cómo empezar

Clona el repositorio, entra en la carpeta `mini-inventario` y verifica las versiones con `node --version`, `npm --version` y `python --version`.
