# Mini Inventario

- El proyecto es una web para registrar y consultar productos de un inventario.
- Usa Node.js 22.20 o posterior dentro de la serie 22 y Python 3.12.
- Haz cada cambio en una rama y abre un pull request para integrarlo.
- Nunca subas archivos .env, llaves, tokens ni otras credenciales.
- Pide aprobación explícita antes de borrar datos o desplegar.
